# 0008 网关下发全局 Codex 启动配置

- 状态：已接受
- 日期：2026-11-28

## 背景

管理员需要为所有 Workspace 设置同一份 Codex 配置和全局指令。配置保存后，下一次启动 Codex 应读到新值，已有容器和会话空间可以继续使用。[C-001](../../CONSTRAINTS.md#c-001-codex-容器可随时丢弃)要求容器可随时丢弃重建。

## 决定

[ADR 0006](0006-dual-channel-codex-gateway.md)规定容器通过实例凭据直接连接控制面的推理入口。该入口也负责向已通过相同准入的实例下发全局启动配置。控制面持有权威版本，每次启动通过同一网关读取，由启动器在授权代次对应的会话空间写入。此读取无需连接上游，沿用既有的绑定及撤销边界。

管理员配置保存为原文。启动器以 Codex 命令行覆盖设置提供网关所需的连接参数，使两层配置各有明确的所有者。[配置分层](../codex-gateway.md#启动配置)

## 取舍

客户端进程启动时同步当前配置。启动增加一次控制面请求，并依赖该读取成功。控制面统一持有文件使重建后的容器可以直接使用当前配置。

否决创建容器时写入 `/etc/cloudex` 的方案。这个方案需要扩展 Host Agent 协议，保存配置后也需要 Rebuild 才能生效，而 Rebuild 会丢弃容器内的 Codex 会话。
