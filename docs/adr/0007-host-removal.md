# 0007 Host 移除与关联记录清理

- 状态：已接受
- 日期：2026-11-27

## 背景

远程 Host 的登记可以移除并同名重建。早期方案采用软删除，使管理员仍可按原 Workspace 或操作 ID 查到历史，也保留了历史中的原 Host ID。这些查询可用于事后核对操作结果，例如删除 Workspace 时是否清除了卷。经复核，项目将归属该 Host 的历史查询保留到登记移除为止。

## 决定

硬删除远程 Agent 或 SSH 直连 Host 的登记，并沿 Workspace 的实际归属级联清理控制面记录。内置 `local`、仍有未删除 Workspace 或未完成操作的 Host 受保护。依赖检查和清理原子生效，管理连接在删除提交成功后关闭。

其他 Host、全局设置和共享 Codex 授权继续保留。远端机器、Agent 部署及 Docker 资源继续保留。[删除范围与接口契约](../api.md#删除-host)

## 后果

登记移除后，原操作历史和幂等回执随关联记录清理。同名登记具有新的 Host ID。[运维步骤](../operations.md#移除远程-host)
